# 📦 Sistema de pedidos

Sistema para recibir, gestionar y consultar pedidos con seguimiento de estados.

## Cliente
- Ver productos, seleccionar cantidades y agregar observaciones.
- Ver subtotal, costo de envío y total.
- Completar datos y confirmar el pedido.
- Recibir un número de pedido.

## Negocio
- Ver pedidos nuevos, productos, cantidades y datos del cliente.
- Cambiar el estado: Pendiente, En preparación, Listo, Enviado, Entregado o Cancelado.
- Buscar pedidos y ver pedidos anteriores.
- Consultar ventas.

**Presupuesto de referencia:** $60.000 aprox.
